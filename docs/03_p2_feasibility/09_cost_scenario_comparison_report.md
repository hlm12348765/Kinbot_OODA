## 1. 文档目的与输入口径

本文用于回答 `Step 51` 提出的 `4` 个问题：

1. 在当前基础功能下，`6000` 元 `BOM` 如何实现。
2. `6000` 元成本下哪些领域会牺牲或打折扣，以及是否损伤产品竞争力。
3. 若成本提高到 `10000` 元，哪些领域应优先投入，收益是什么。
4. 不同成本方案是否会改变技术架构与核心方案设计。

本文不是最终采购报价单，也不冻结器件清单。下文金额均为 `2027 Q1`、`30K` 量级下的工程估算口径，用于判断资源消耗、风险转移和方案优先级。

当前沿用 [08_system_tradeoff_model_and_priority_matrix.md](08_system_tradeoff_model_and_priority_matrix.md) 的权衡模型：

1. 先过运动安全、隐私合规、断网本地安全闭环、可制造性与高端产品感底线。
2. 再比较价值贡献、资源消耗、风险转移和证据门槛。
3. 并行保留 `A: 5000 到 6000 元 BOM 约束线` 与 `B: 10000 元 BOM 战略线`。
4. 不允许 `B` 情景覆盖 `A` 情景，除非用户和商业拆解明确升级主线。

## 2. Step 51 新增事实

| 项目 | Step 51 输入 | 成本分析含义 |
| --- | --- | --- |
| 量产估算规模 | 当前按 `30K` 量级估算 `2027 Q1` 成本 | 不按样机价或极小批量价判断，但仍不能假定已有大规模摊销优势 |
| `S100Pro` 小系统 | 官方样品价 `249 USD`，不含税，`30K` 量级至少九折；小系统仅含 `SoC / PMIC` 等芯片，不含存储 | `249 * 0.9 * 6.9 ≈ 1546 元`，且不能与存储价重叠抵扣 |
| 存储 | `12GB RAM + 64GB eMMC` 约 `200 USD`，不含税 | `200 * 6.9 ≈ 1380 元`，独立于小系统 |
| 端侧替代路线 | 地瓜计划 `2027 Q1` 推出 `X7Pro`，成本更低，`CPU` 稍弱，算力对标 `S100` 标准版，内存位宽提升，大模型推理性能更强；也在监控其他芯片 | `S100Pro` 不应直接视为唯一量产默认解，需建立芯片替代观察门 |
| 头部方案 | 紧凑轻量头部，升级为四自由度，均有编码器 | 增强拟人表达和主动观察，但增加头颈机构、编码器、线束、寿命和装配压力 |
| 主传感器 | 主传感器为双目相机，成本 `200 到 500 元`；运动侧除双目外，仅 `IMU`、超声波和轮速计等基础传感 | 纯视觉主线进一步收敛，主动传感成本不进入量产主线 |
| 轮毂电机 | 大幅提高自研程度并缩减尺寸，以降低成本 | `C4` 有降本机会，但不能牺牲低噪、可靠和过门槛底线 |
| 药箱 | 目标做简单，靠视觉模型判断吃药 | `C6/T8` 主动降复杂度，但把一部分识别压力转移到 `C1/C2` |
| 整机质量 | 目标 `<28kg`，各领域都在减重 | 成本分析必须同步看重量、结构、续航、运输和家庭通行 |
| 权衡优先级 | 已与产品经理对齐，以 `08` 文档用户修改为当前口径 | 后续排序以健康、安全可靠、具身到人和高端产品感的组合结果判断 |

## 3. 两档成本的战略意图

| 情景 | 提出者 / 状态 | 核心意图 | 不能误用为 |
| --- | --- | --- | --- |
| `A: 6000 元 BOM 约束线` | 业务分管领导提出，当前强约束线 | 用极致成本纪律倒逼技术卓越，把功能投入放在真实 `ROI` 上，让后来者难以在同等成本下做出可竞争产品 | 把产品做成廉价、低配或体验打折的机器人 |
| `B: 10000 元 BOM 战略线` | 董事长提出，当前战略情景 | 先抓顶尖用户和有影响力圈层，用更好品质、精致感和可靠性支撑 `23999 到 29999` 价格带，并保留 `GB` 端和项目机会 | 直接放松工程纪律，或者把 `10000` 元写成已确认主线 |

关键判断：

1. `6000` 元线是产品竞争门槛，不是简单降配线。
2. `10000` 元线是战略上修选项，不是所有模块一起涨价的理由。
3. 两档成本的合理关系应是“同一架构基线下的可裁剪 / 可增强选项包”，而不是两套产品架构。

## 4. `C1-C7` 成本桶重估

### 4.1 `C1` 已经成为最大变量

按 Step 51 当前口径：

| 子项 | 计算口径 | 估算成本 | 说明 |
| --- | --- | ---: | --- |
| `S100Pro` 小系统 | `249 USD * 0.9 * 6.9` | `约 1546 元` | 仅含 `SoC / PMIC` 等芯片，不含存储，不含税 |
| `12GB RAM + 64GB eMMC` | `200 USD * 6.9` | `约 1380 元` | 独立于小系统，不含税 |
| 小系统 + 存储合计 | `1546 + 1380` | `约 2926 元` | 尚未包含 `PCB`、连接器、散热、税费、制造余量 |

这意味着旧的 `C1 端侧算力与存储 1100 到 1700 元` 区间已经被击穿。若坚持 `S100Pro + 12GB + 64GB` 作为默认量产配置，`C1` 不再是局部超标，而是会结构性挤压 `C2-C7`。

进一步判断：

1. `S100Pro` 可以作为边界验证或高配情景基准，但不能未经证明直接写成 `6000` 元线默认解。
2. `X7Pro` 或其他中国端侧芯片需要进入 `C1` 替代路线观察，重点验证大模型推理性能、内存位宽、热稳态、接口、供应和量产价格。
3. `12GB + 64GB` 在 Step 51 中是计划配置，但若 `6000` 元线要成立，必须把 `64GB` 存储的必要性和可替代策略单独验证。
4. `C1` 的决策不能再只看纸面算力，而要同时看 `TTFT / TPS / 热稳态 / 内存占用 / 视觉链路并发 / 供应风险 / 单价`。

### 4.2 成本桶重估方向

| 成本桶 | 原滚动基线角色 | Step 51 后的判断 | 对 `6000` 元线的含义 | 对 `10000` 元线的含义 |
| --- | --- | --- | --- | --- |
| `C1 端侧算力与存储` | 过去按 `1100 到 1700` 监控 | `S100Pro + 12GB + 64GB` 仅核心芯片与存储已约 `2926` | 必须找更低成本芯片 / 存储组合，或把 `S100Pro` 降为边界验证线 | 可承接更强推理和产品感，但必须证明用户可感知收益 |
| `C2 相机与基础传感` | 纯视觉降本主战场 | 双目 `200 到 500`，运动侧只保留基础传感 | 继续坚持不用激光雷达 / 深度相机，不随意加相机 | 可升级相机低照、动态范围、标定和可靠性，不扩张主动传感主线 |
| `C3 音频与交互器件` | 中低压力 | 音频成本相对低，屏幕与外观耦合更关键 | 控制屏幕和灯光规格，不牺牲基本舒适交互 | 增加声学舒适度、屏幕质感和低打扰表达 |
| `C4 底盘与运动系统` | 稳定但强耦合 | 轮毂电机自研和小型化是降本抓手 | 可以降零件数和尺寸，不能牺牲低噪、可靠、过门槛 | 优先投入低噪声、寿命、驱动余量和回充可靠性 |
| `C5 电池、电源与热设计` | 上行且未冻结 | `C1` 上行会同步拉高功耗和热压力 | 以控涨为主，不能靠削电池和热安全压成本 | 优先补热设计、电源保护和续航一致性 |
| `C6 储物仓、结构与外观件` | 结构降本主战场 | 药箱做简单，整机 `<28kg` | 简化药箱、压零件数、做轻量结构 | 用于提升外观质感、装配公差、维护便利和材料手感 |
| `C7 制造、测试与校准余量` | 流程降本主战场 | 四自由度头、双目和自研轮毂提高校准 / 产测要求 | 必须自动化产测与标定，否则难进 `6000` | 投入治具、产测自动化、可靠性筛选和售后可维护性 |

## 5. `6000` 元方案如何实现

`6000` 元线的核心不是“什么都用最便宜”，而是把每一笔成本都绑定到健康闭环、可信运动、聪明感、可量产和高端产品感底线。

### 5.1 必须采取的降本动作

| 领域 | `6000` 元线动作 | 不能越过的底线 |
| --- | --- | --- |
| 端侧算力 | `S100Pro` 不直接默认为唯一量产解；建立 `X7Pro / S100 标准版级别 / 其他国产芯片` 替代评测；压低常驻模型和存储占用 | 本地安全、视觉、导航和首响应体验不能明显变笨 |
| 存储 | 重新验证 `64GB eMMC` 的必要性；地图、日志、模型、OTA 分层管理 | 不能损伤可回放、可审计和 OTA 安全 |
| 传感器 | 坚持双目主传感 + `IMU / 超声波 / 轮速计`，不加入激光雷达、深度相机和更多主动传感 | 不能让导航、近场安全和低照能力失控 |
| 头部 | 保留紧凑轻量四自由度的产品差异化，但控制电机、编码器、线束和结构复杂度 | 不能牺牲头部灵动感、寿命和线束可靠性 |
| 底盘 | 轮毂电机自研、小型化、零件数压缩 | 不能牺牲低噪、稳定、回充和过门槛能力 |
| 药箱 | 简化机构，靠视觉模型辅助判断吃药；保留状态记录和交接确认 | 不能牺牲防夹手、误取风险和用药闭环证据 |
| 结构外观 | 轻量化、功能件合并、DFM / DFMA 前置 | 不能做出廉价 IoT 感或装配粗糙感 |
| 产测校准 | 双目、头颈、麦阵、轮毂的自动化校准提前设计 | 不能把成本压给产线人工返工和售后故障 |

### 5.2 可能牺牲或打折扣的领域

| 牺牲项 | 具体表现 | 是否损伤竞争力 | 处理建议 |
| --- | --- | --- | --- |
| 算力余量 | 不默认上最强 `S100Pro` 或更大存储，模型规模和常驻链路受限 | 中等风险；会影响“聪明感”上限 | 用模型压缩、事件触发、端云边界和芯片替代评测补偿 |
| 低照 / 复杂视觉冗余 | 不加主动传感和更多相机 | 高风险；若视觉不过线会直接伤害导航和安全 | 必须把双目低照、反光、弱纹理、遮挡列为 Phase 5 压测 |
| 药箱高级机构 | 容量、自动分拣、防错拿能力收敛 | 低到中风险；取决于健康闭环定位 | 一代保留状态记录、交接确认和视觉识别，复杂分拣后置 |
| 运动性能余量 | 不追求炫技和过强速度，底盘裕量受控 | 低风险；只要安全、安静、稳定成立 | 把低噪声、平顺和回充成功率作为底线，不为速度堆料 |
| 外观 / 材料余量 | 高成本材质、复杂灯光、大屏规格被压缩 | 中风险；可能伤害高端产品感 | 用比例、装配、公差、交互节奏和声学质感补偿 |
| 可靠性冗余 | 结构、散热、产测预算更紧 | 高风险；可能转为售后成本 | `6000` 元也必须保留关键寿命、热和产测余量 |

结论：`6000` 元线可作为强约束目标继续推进，但不是当前配置自然落入的结果。尤其 `C1` 若按 `S100Pro + 12GB + 64GB` 计算，必须通过芯片替代、存储策略、结构降本和产测自动化共同回收，否则整机 `BOM` 很难成立。

## 6. `10000` 元方案优先投入项

`10000` 元线的合理用法，是把新增约 `4000` 元投入到用户可感知、量产风险可降低、服务价值可放大的位置。不能用来简单堆规格。

### 6.1 优先投入

| 优先级 | 投入方向 | 建议投入内容 | 预期收益 |
| --- | --- | --- | --- |
| `1` | 头颈四自由度可靠性与表达 | 更可靠编码器、线束寿命、静音传动、装配精度、寿命验证 | 强化“灵动、温暖、精致”的第一眼差异化 |
| `2` | 低噪声运动与回充 | 更好轮毂电机、驱动余量、减振、轮组、回充对接可靠性 | 提升共居可信度和高端感，降低售后风险 |
| `3` | 电源、热设计和续航一致性 | 更稳电池、电源保护、散热路径、热稳态设计 | 把大模型和运动交互的热 / 续航风险压住 |
| `4` | 双目与低照视觉质量 | 更好双目模组、镜头、ISP、标定治具、低照验证 | 提升纯视觉路线的成功率和安全边界 |
| `5` | 结构装配质感与轻量化 | 更好材料、公差、外观件、维护结构、轻量化件 | 支撑 `23999 到 29999` 价格带的品质认知 |
| `6` | 产测、校准和可靠性筛选 | 自动化标定、治具、老化测试、日志追溯、出厂自检 | 降低批量一致性和售后成本 |
| `7` | 端侧算力高配或边界验证 | `S100Pro / 12GB + 64GB` 可作为高配验证线 | 提升模型体验，但必须证明真实用户感知收益 |

### 6.2 不应优先投入

1. 不优先加激光雷达、深度相机或主动传感产品级 fallback。
2. 不优先扩大药箱容量和复杂分拣机构。
3. 不优先上更复杂灯光、娱乐表达和非核心生态接入。
4. 不优先用坐席长期兜底本体失败链路。
5. 不把更高 `BOM` 直接转化为更重、更大、更热、更难维修的整机。

### 6.3 `10000` 元线的收益判断

`10000` 元线真正值得购买的是：

1. 纯视觉路线更稳，而不是传感路线回退。
2. 头部更灵动可靠，而不是头部更重更复杂。
3. 运动更安静可信，而不是速度更炫。
4. 结构更精致可维护，而不是装饰更多。
5. 量产一致性更高，而不是单台样机更好看。
6. 服务与数据闭环更可信，而不是人工坐席长期替机器兜底。

## 7. 两档成本对架构和核心方案的影响

### 7.1 不应改变的架构基线

无论 `6000` 元线还是 `10000` 元线，都不建议改变以下主线：

1. 一代传感主线继续是纯视觉，不把激光雷达或深度相机升级为产品 fallback。
2. 头部继续采用紧凑轻量头部，躯干保留内容屏。
3. 药箱继续做简单，围绕安全开关、状态记录、交接确认和视觉辅助判断吃药。
4. 整体继续按 `S1-S7` 工作包推进，不新增并列架构体系。
5. 原始敏感数据仍以端侧处理为原则，只保留受控回流能力。
6. 整机质量 `<28kg` 继续作为系统级约束。

### 7.2 会改变的方案层选项

| 领域 | `6000` 元线 | `10000` 元线 |
| --- | --- | --- |
| 算力 | 优先找低成本可量产芯片和更紧模型调度，`S100Pro` 不默认进低成本线 | 允许 `S100Pro + 12GB + 64GB` 作为高配 / 边界验证线，但需证明体验收益 |
| 存储 | 严格管理模型、地图、日志和 OTA 空间 | 保留更大本地缓存、回放和边界验证空间 |
| 双目 | 优先满足基础导航、找人和安全 | 可上更好低照、动态范围和标定能力 |
| 头颈 | 保留四自由度，但严格控制机构和线束成本 | 加强寿命、静音、编码器精度和装配一致性 |
| 底盘 | 自研小型轮毂和基础传感组合 | 加强低噪、寿命、回充可靠和越障余量 |
| 药箱 | 简化机构，不扩大容量和自动分拣 | 只补安全、质感和确认体验，不做复杂药房化 |
| 结构外观 | DFM 优先，压零件数和重量 | 提升材料、公差、维修便利和高端产品感 |
| 产测售后 | 最低自动化能力必须前置 | 加强老化、校准、可追溯和售后诊断 |

### 7.3 推荐架构口径

推荐采用：

```text
一套产品架构基线
+ 两个 BOM 情景
+ 若干可裁剪 / 可增强选项包
+ 同一套 Phase 5 证据门
```

不建议采用：

```text
6000 元一套低配架构
+ 10000 元一套高配架构
```

原因：

1. 两套架构会让工程、验证、供应链、产测、售后和文档全部翻倍。
2. 一代当前最大的风险不是“功能不够多”，而是纯视觉、端侧算力、头颈四自由度、低噪运动和量产一致性同时过门。
3. 如果 `10000` 元线最终成立，也应优先买同一架构的质量和余量，而不是引入新的体系复杂度。

## 8. 推荐决策与后续验证项

### 8.1 推荐决策

1. 当前继续保留 `6000` 元 `BOM` 约束线，作为技术卓越和成本纪律的强牵引。
2. 同时保留 `10000` 元 `BOM` 战略线，作为高端品牌策略、`29999` 定价假设和 `KBT-57` 商业拆解的对照情景。
3. `C1` 必须从原区间重开，不再沿用 `1100 到 1700 元` 作为自然可达假设。
4. `S100Pro + 12GB + 64GB` 当前更适合作为高配 / 边界验证口径；`6000` 元线必须评估 `X7Pro` 和其他国产端侧方案。
5. `10000` 元线只投用户可感知品质、可靠性、热电安全、纯视觉稳定性、产测校准和售后可维护性。
6. 技术架构不拆成两套，保持同一纯视觉主线和紧凑轻量头部主线。

## 9. 复杂度自检

现在的架构是不是太复杂了？

如果为 `6000` 元和 `10000` 元分别做两套架构，答案是“是”。这会制造两套硬件、两套验证、两套供应链和两套售后口径，复杂度会明显超过一代项目当前承载能力。

如果采用“一套架构基线 + 双 `BOM` 情景 + 可裁剪选项包”，答案是“可控”。它保留了成本纪律，也给董事长提出的高端品牌策略留下了评审空间。

最终建议：

1. `6000` 元线继续作为默认约束，推动芯片替代、结构简化、药箱简化、传感收敛和产测自动化。
2. `10000` 元线只作为战略情景保留，等待 `KBT-57` 对 `29999` 定价、渠道、首批规模、服务和租售模式完成商业拆解。
3. 任何从 `6000` 元切到 `10000` 元的上修，都必须说清新增成本买到了什么用户可感知价值、什么可靠性余量或什么量产风险下降。
