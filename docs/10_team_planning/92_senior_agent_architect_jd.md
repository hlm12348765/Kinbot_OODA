## 岗位使命

让大模型与多模态智能可靠地进入物理世界。

你将负责下一代家庭机器人 Agentic System 的总体架构，把模型的理解与决策转化为机器人可安全执行、可验证、可恢复的真实任务。这个岗位不只交付单点 Agent 功能，而是从零建立机器人 Agent Runtime、工具与动作协议、安全治理、评测体系和团队工程标准，持续把前沿能力沉淀为可产品化的系统底座。

## 你将负责

1. 负责具身智能机器人 Agentic System 的总体架构、技术路线和演进规划，主导关键技术决策与架构评审。
2. 设计端、云、设备协同的 Agent Runtime，覆盖任务状态、上下文与记忆、规划与执行、结果校验、`Checkpoint / Resume`、并发隔离和异常恢复。
3. 建立物理设备 `Tool / Action` 协议与安全治理体系，定义参数校验、权限、幂等、超时、回滚、审计、`HITL` 和 `fail-safe` 机制。
4. 推动 `Prompt`、`RAG`、模型路由、工具调用、工作流、多 Agent 协同和 API 封装的平台化，明确通用底座与场景应用的边界。
5. 建设 `AgentOps` 与评测体系，打通 `Trace`、回放、离线评测、线上指标、失败分类和版本回归，让效果与安全问题可度量、可复现、可优化。
6. 主导至少一条机器人关键 Agent 链路从方案、开发到真实设备验证，与端侧应用、云服务、交互、算法、运动控制和测试团队共同完成产品化闭环。
7. 带领 Agent 团队，建立架构规范、工程标准和 AI-Native 研发方式，持续提升交付质量与迭代效率。

## 我们期待你

1. 具备 `5` 年以上软件工程经验；有 `2` 年以上大模型应用 / Agent 工程化经验，或主导过同等复杂度的生产级 Agent 系统。
2. 至少完整负责过一类生产级 Agent、RAG 或智能任务系统，能够讲清真实 owner 边界、上线规模、稳定性、安全和评测结果。
3. 熟悉 `LLM / VLM` 接入、`Prompt`、`RAG`、`Tool Calling`、`Workflow / 状态机`、模型路由和上下文工程。
4. 具备扎实的软件架构能力，能够处理分布式状态、异步任务、消息幂等、故障恢复、可观测和端云设备协同问题。
5. 对物理设备工具调用的安全边界有成熟认知，能设计权限、确认、校验、恢复、回滚和审计机制。
6. 能带领小团队，也愿意亲自写核心代码；熟练使用 `Codex`、`Claude Code` 等 AI 编程工具，把 AI-Native 方式真正融入研发流程。
7. 具备良好的跨团队协同与结果推动能力，能在不确定环境中拆解问题、建立共识并持续交付。

## 加分项

1. 有机器人、无人机、自动驾驶、智能终端或 IoT 设备云经验。
2. 有 `Long-running Agent`、`HITL`、`Checkpoint / Resume`、多 Agent、端云协同或弱网恢复实践。
3. 有多模态交互、长期记忆、Agent 评测、安全治理或 `OpenClaw` 等前沿 Agent 能力落地经验。
4. 有从 `0` 到 `1` 建设技术体系、带领小团队或推动跨团队复杂项目的经历。

## 入职后重点成果

### 前 60 天

1. 完成现有交互与 Agent 技术栈梳理。
2. 冻结首版 Agentic System 分层、核心接口、状态模型、安全边界和演进路线。
3. 建立架构评审、关键链路 Trace 和 AI-Native 研发的最小工作机制。

### 前 90 天

1. 主导至少 `1` 条机器人关键 Agent 链路在真实设备上跑通。
2. 闭环覆盖工具调用、结果回写、人工确认、异常恢复和全链路可观测。
3. 建立首版离线评测与版本回归基线，完成至少 `1` 轮量化优化。

### 半年内

1. 形成可复用的 Agent Runtime、物理工具安全和 AgentOps 基线。
2. 支撑多个家庭机器人场景在统一架构下快速接入和迭代。
3. 形成职责清晰、能持续交付的 Agent 技术团队和工程标准。

## 为什么值得加入

1. **定义核心架构，而非只实现单点功能**：你将决定机器人如何理解任务、调用真实设备并安全完成闭环。
2. **问题真正跨越模型与物理世界**：工作同时覆盖模型、端侧、云侧和实体设备，技术深度与系统复杂度远高于纯软件 Agent。
3. **离真实产品结果很近**：能力可以在家庭机器人和真实用户场景中快速验证，架构决策能直接影响体验、安全与交付效率。
4. **从零建立长期差异化能力**：把 Agent Runtime、AgentOps、物理工具安全和 AI-Native 研发方式沉淀为团队长期底座。
5. **拥有明确的技术影响力**：作为早期核心技术负责人参与长期投入的家庭机器人项目，拥有架构决策、团队建设和关键链路落地空间。
