## 岗位使命

让家庭机器人的每一次移动都平顺、安全、安静且可信，并持续进化。

你将负责运行在 SoC 上的机器人运动控制算法，把导航与规划结果转化为可稳定执行的整机运动。当前以经典控制和状态估计为产品基线，逐步建立向模仿学习、深度强化学习和自适应控制演进的数据、仿真、评测与安全体系。

## 你将负责

1. 负责家庭机器人 SoC 侧运动控制算法研发与工程化落地，覆盖底盘状态估计、轨迹跟踪、速度 / 转向控制、平顺性及近人安全约束。
2. 建设以经典控制为当前主线的算法底座，应用 `PID / LQR / MPC`、观测器和系统辨识等方法持续提升运动性能。
3. 设计导航 / 规划、SoC 控制算法、安全模块与 MCU 执行层之间的接口，保证时延有界、状态可观测、异常可降级。
4. 建立 `SIL / HIL / 真机`评测、数据采集和回放体系，以轨迹误差、平顺性、时延、安全和恢复能力驱动算法迭代。
5. 探索模仿学习、深度强化学习和 `residual policy`，建立仿真训练、`sim-to-real`、安全约束和受控灰度验证路径。

## 我们期待你

1. 硕士及以上学历优先，具备 `3` 年以上移动机器人、自动驾驶、无人机或相关运动控制算法经验。
2. 熟悉机器人运动学、状态估计和控制理论，掌握 `PID / LQR / MPC` 等至少两类方法，并有真机闭环经验。
3. 熟练使用 `C++ / Python / Linux / ROS 2`，能够在 SoC 上完成算法部署、性能优化和系统问题定位。
4. 具备仿真、数据分析和量化评测能力，能把算法从离线效果推进到稳定可交付的整机链路。
5. 能清楚区分算法控制与电机硬实时控制，愿意与导航、嵌入式、硬件、安全和测试团队共同对整机结果负责。

## 加分项

1. 有 `PyTorch`、深度强化学习、模仿学习、`Isaac Lab`、`MuJoCo` 或 `Gazebo` 实践。
2. 熟悉 SoC 实时调度、导航规划接口、MCU 通信或电机控制边界。
3. 有消费级机器人低速近人、安全、静音、平顺性或复杂地面适应优化经验。
4. 有从仿真到真机、从算法原型到量产产品的完整闭环经验。

## 入职后重点成果

### 前 60 天

1. 完成现有运动控制链路、SoC / MCU 边界和关键技术债梳理。
2. 冻结首版控制接口、状态定义和量化评测基线。
3. 跑通 `SIL / HIL / 真机`数据采集、回放和问题复现链路。

### 前 90 天

1. 在 SoC 上交付至少 `1` 条运动控制关键链路并完成真机闭环。
2. 围绕轨迹误差、平顺性、控制时延、安全和异常恢复完成至少 `1` 轮量化优化。
3. 完成 `1` 个学习型控制原型及 `sim-to-real` 可行性评估，明确安全门、收益门槛和后续路线。

## 为什么值得加入

1. **离产品体验极近**：算法效果会直接反映在机器人是否平顺、安全、安静和可信上。
2. **兼具当期交付与长期上限**：当前做经典控制产品化，后续逐步进入模仿学习、深度强化学习和自适应运动智能。
3. **拥有完整真机闭环**：工作覆盖仿真、SoC 部署、MCU 执行、整机评测和真实家庭场景，而不只停留在离线指标。
4. **可以定义关键技术边界**：参与建立导航 / 规划、SoC 控制与 MCU 执行之间长期可复用的运动智能底座。

## 内部职责边界

本节供招聘与组织对齐使用，不建议放入外发 JD。

| 层级 | 默认主责 | 不作为默认主责 |
| --- | --- | --- |
| SoC 运动控制算法 | 状态估计、轨迹跟踪、速度 / 转向控制、约束优化、平顺性、学习型策略与评测 | 电流环、PWM、功率器件驱动 |
| MCU 与电机控制 | 电流 / 速度等硬实时闭环、执行器驱动、底层保护、看门狗与急停执行 | 高层轨迹策略、学习型策略训练 |
| 导航与规划 | 定位、路径与局部轨迹生成、环境与障碍约束 | 电机硬实时执行和功率驱动 |

深度强化学习是受控演进方向，不替代确定性的安全约束、急停机制和 MCU 硬实时保护。学习型策略进入产品链路前，必须通过离线评测、仿真、`HIL`、封闭场地真机和阶段化安全门。
