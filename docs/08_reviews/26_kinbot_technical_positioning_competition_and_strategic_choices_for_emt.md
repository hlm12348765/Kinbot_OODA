## 2. 执行摘要

Kinbot 是当前中国唯一一个以”家庭共居智能体”为架构母命题、采用纯视觉 + 端侧导航基础模型路线、并已进入量产预备阶段的居家养老机器人。

当前主线下，Kinbot 的目标不是做”最通用的机器人”，也不是做”会说话的移动摄像头”，而是做一台具备 `高质量交互 + 强语义移动 + 长期家庭记忆 + 安全可审计执行链` 、并能支撑 `20000 到 30000 元` 售价区间高端产品感的轮式家庭机器人。

如果按当前规划兑现，Kinbot 的技术位势将表现为：

- 在系统完整度、长期家庭记忆、找人找物、共存移动和高端产品完成度上，显著强于当前多数家用巡护 / 陪伴 / 远程看护机器人。
- 在机械操作和通用具身能力上，明显弱于类人形和通用操作机器人，但这是有意为之的战略裁剪。
- 在短期产品竞争中，对位的是 `Ballie / Astro / EBO X / temi` 这类家用移动陪伴 / 看护机器人。
- 在中期技术叙事竞争中，还同时面对 `1X NEO / Figure 03 / Optimus` 这类家庭类人形路线。

因此，Kinbot 当前路线的本质不是“去做人形终局第一”，而是：

`先占据高端家庭移动交互机器人的产品化高地`

## 3. Kinbot 预期达到的技术状态

### 3.1 总体定位

按当前分支 `codex/kinbot_co_living_agent@498a4d7` 的主线，Kinbot 当前的系统级定位是：

- 家庭共居智能体
- 轮式移动交互机器人
- 中国大陆居家养老首发
- `Robot + App + 最小云` 的最小交付闭环
- `核心闭环强、服务闭环轻、技术突破集中`

### 3.1.1 技术量化锚点

| 维度 | 量化锚点 | 来源 |
| --- | --- | --- |
| 端侧导航模型 | `4B` 参数 Student，由 `27B` Teacher 多轮蒸馏 | NFM 模型设计 |
| 端侧算力 | 地瓜 `S100 Pro`（`128 TOPS`），`12GB RAM + 32GB Flash` | 软硬件选型矩阵 |
| 导航任务覆盖 | `5` 类任务（`T1-T5`），P0 覆盖 `T1 / T2 / T3 / T4A` | 导航基本问题与数据设计 |
| 记忆体系 | `3` 层记忆平面，`6` 类长期记忆，`7` 实体 World State | 长期记忆设计 + World State |
| 空间表达 | 双帧体系：`semantic_global_frame + local_metric_frame` | NFM 角色分析 |
| 夜间闭环 | `4` 阶段（昼夜同轨自学习 → 锚点增强 → 授权重建 → `AHPW`） | 夜间闭环研究 |
| 视觉传感器 | `1` 组双目 + `2` 个单目 RGB，自研深度估计 | 总体架构 |
| 整机 BOM | `5000 到 6000 元`，`7` 个成本桶（`C1-C7`） | 软硬件选型矩阵 |
| 评估指标 | 以 `TTFT`、稳态 `TPS`、热稳态衰减后持续 `TPS` 为核心 | 软硬件选型矩阵 |

### 3.2 导航与空间智能

在导航侧，Kinbot 当前路线不是端到端动作模型，而是：

- `NFM` 作为端侧导航模型
- `semantic_navigation_policy + social_mobility_policy`
- `semantic_global_frame + local_metric_frame`
- `World State`
- 经典导航与安全链

因此，Kinbot 预期达到的不是“导航 benchmark 单点最强”，而是：

- 能完成有任务时的到达、找人、找物、跟随、靠近、恢复
- 能完成无显式任务时的礼让、靠边、等待、低扰动 reposition
- 能在家庭真实环境中把空间语义、人物身份、长期记忆和局部安全执行串成一个闭环

如果该路线兑现，Kinbot 的导航系统完整度将处于国内家庭养老机器人里非常靠前的水平。

### 3.3 交互与记忆

在交互侧，Kinbot 当前采用的是：

- `cloud_interaction_model`
- `edge_interaction_reflex`
- `world_state_memory`
- `dialogue_memory_plane / embodied_memory_plane / runtime_world_state`

这意味着 Kinbot 预期实现的，不是单次对话能力最强，而是：

- 唤醒后低时延首字响应
- 边移动边表达
- 复杂交互由云侧增强
- 长期对话记忆与长期空间记忆协同
- 导航失败、找不到目标、需要澄清时，能把状态回流到交互层

这种“交互-运动-记忆”协同，在当前公开家用机器人里并不常见。

### 3.4 工程与成本状态

Kinbot 当前量产主线已经明确：

- 纯视觉主线
- `1` 组双目 + `2` 个单目
- `12GB RAM + 32GB Flash`
- `BOM 5000 到 6000 元`
- 纯视觉不过线时，优先调节奏，不回退 `LiDAR / 深度相机`

因此，Kinbot 的目标技术状态不是“无限堆料”，而是：

- 在强资源约束下，把产品能力做成
- 在高端产品感和量产可行性之间找到平衡
- 以系统设计而不是传感器堆料建立壁垒

### 4.3 对竞品格局的直接判断

更准确的结论不是”Kinbot 没有竞品”，而是：

- 在中国大陆居家养老场景，当前没有技术规划深度接近 Kinbot 的直接产品竞品。国内已有养老机器人产品多停留在 LiDAR + SLAM + ASR/TTS 的功能堆叠层级，缺乏系统级语义导航、长期记忆和家庭关系建模能力。
- 最大的短期威胁不是来自同类机器人，而是来自”用户是否愿意为 `2 到 3 万元` 的家庭机器人付费”这一市场验证问题。Amazon Astro 的消费端收缩已经验证了这个风险的真实性。
- 在中期技术与心智竞争层，Kinbot 面对的压力很强，尤其来自家庭类人形路线（`1X NEO / Figure 03 / 优必选 Walker`）。
- 因此 Kinbot 必须同时回答两件事：
  - 为什么它比当前家用移动机器人和养老机器人更强
  - 为什么它虽然不是人形，却仍然值得用户先买

## 5. Kinbot 为了赢市场刻意做出的关键抉择

### 5.1 不做人形、不做机械臂，只做轮式移动交互

**做了什么**

- 固定为轮式移动交互机器人
- 不纳入机械臂和复杂物理操作
- 不走双足人形路线

**为什么**

- 先把”移动 + 交互 + 记忆 + 看护”闭环做到稳定
- 在 `BOM / 量产 / 外观 / 噪声 / 功耗` 上更可控
- 避开类人形与通用操作的高复杂度战场
- 家庭人形机器人当前 BOM 在 `5 到 10 万元` 以上，不在 Kinbot 的 `2 到 3 万元` 售价区间
- 双足行走在有老人的家庭环境（地毯、门槛、杂物、湿滑地面）中的可靠性远未达到产品级
- 轮式底盘在续航、噪声、稳定性和成本上对养老场景有结构性优势
- Kinbot 架构层已为未来本体形态升级保留接口：执行范式层与本体实体层解耦，`NFM` 输出语义子目标而非底盘指令，底盘形态变更不需要重写导航智能

**必要性**

- `极高`

**风险与代价**

- 在技术叙事竞争中，”轮式”可能被人形路线的媒体声量压制，需要在市场沟通中持续强调”产品化高地”而非”终局形态”
- 如果家庭人形在 `2028-2029` 年成本快速下降到可接受区间，Kinbot 需要及时启动本体形态升级

### 5.2 云侧交互大模型 + 端侧 `NFM`

**做了什么**

- 云侧负责更强交互
- 端侧 `NFM` 负责导航与共存移动
- 端侧反射层负责低时延响应

**为什么**

- 既要对话体验，又要安全、离线、稳定
- 全云不安全，全端交互质量不够

**必要性**

- `极高`

### 5.3 `NFM` 不直接控底盘，保留经典导航与安全链

**做了什么**

- `NFM` 输出语义子目标、搜索策略、恢复策略、共存移动约束
- 经典导航负责局部规划、轨迹生成、控制与安全执行
- `27B Teacher` 多轮蒸馏到 `4B Student`，在 `12GB RAM` 约束下部署

**为什么**

- 家庭场景必须可审计、可降级、可恢复
- 当前公开最可靠的产品化路线也仍然保留分层（`NavFoM@ICLR2026`、`GR00T N1.6`、`LISN` 均保留 local planner）
- 用 VLA 的方法论提升 VLN 的能力上限，而不是用 VLA 的问题定义取代 VLN 的产品定义

**必要性**

- `极高`

**风险与代价**

- `27B → 4B` 蒸馏损失如果超预期，`4B` 能力天花板可能不足以覆盖 `T3`（共存移动）和 `T4`（跨会话适配）的完整需求
- 分层架构在极端情况下可能出现 `NFM` 语义判断与局部规划不一致的问题，需要持续迭代语义子目标到局部规划的桥接质量
- 缓解手段：`27B Teacher` 可持续升级基座，`4B Student` 的能力天花板跟着上移；`12GB + 64GB` 边界验证线为更大模型保留观察窗口

### 5.4 把 `World State` 和长期家庭记忆做成壁垒

**做了什么**

- 七实体 `World State`
- 空间双帧
- 长期对话记忆、长期空间记忆、任务状态记忆协同

**为什么**

- 家庭机器人真正难的是“理解这个家并持续记住”
- 没有这层，只会变成每次重新猜的机器人

**必要性**

- `极高`

### 5.5 把 `social_mobility` 单独拎出来

**做了什么**

- 不把共存移动硬塞进普通导航策略
- 专门建 `social_mobility_policy`

**为什么**

- 家庭共居不只是避障
- 还包括礼让、靠边、正对、低打扰接近、等待

**必要性**

- `高到极高`

### 5.6 坚持纯视觉主线

**做了什么**

- `1` 组双目 + `2` 个单目 RGB + 自研深度估计模型
- `LiDAR / 深度相机` 只做研发阶段真值参考，不进入产品 fallback

**为什么**

- BOM 优势：省去 LiDAR / 深度相机可降低 `C2` 成本桶 `300 到 500 元`，在 `5000 到 6000 元` BOM 预算下至关重要
- 产品美学：纯视觉方案更容易实现"聪明、温暖、精致"的高端外观，LiDAR 凸起难以与高端产品感兼容
- 技术壁垒：自研深度估计模型 + 家庭数据可形成长期技术壁垒
- 趋势对齐：智驾领域纯视觉路线已被验证可行，室内场景结构化程度更高

**必要性**

- `高`

**风险与代价**

这是当前路线最大的工程赌注。具体风险：

- 若纯视觉在 `2026 Q3` 阶段门无法达标，按既定策略调整产品节奏而非回退 LiDAR，这意味着交付窗口可能后移
- 夜间、强逆光、高反射等极端光照条件下，纯视觉深度估计精度可能不足以支撑安全导航
- 缓解手段：夜间 `4` 阶段闭环方案已纳入研究主线；阶段门前以 `TTFT / TPS` 和真实场景通过率为硬评判标准，不以纸面指标自欺

## 6. 对 EMT 的直接结论

对 `EMT`，更准确的汇报口径应是：

1. Kinbot 当前不是在竞争“谁是最像未来终局的人形机器人”，而是在竞争“谁最先做成高端家庭移动交互产品”。
2. 它的直接产品竞品主要是 `Ballie / Astro / EBO X / temi`，前瞻技术竞品则包括 `1X NEO / Figure 03 / Optimus`。
3. Kinbot 当前所有关键抉择，本质上都是在绕开人形主战场，先占据家庭移动交互机器人的产品化高地。

对 `EMT` 来说，真正需要判断的不是：

- Kinbot 是否已经是最强机器人

而是：

- 当前这些刻意的裁剪和押注，能否让集团在 `2 到 3 年` 内先拿下“高端家庭移动交互机器人”的第一张门票。

## 7. 修订后的核心一句话

Kinbot 当前的技术路线不是去赌”最激进的终局机器人”，而是去赌一条更可能率先成立的路线：

`在家庭人形机器人尚需 3 到 5 年才能达到产品级可靠性的窗口期内，用系统完整度、家庭场景深度适配、纯视觉成本优势和长期记忆壁垒，抢先占据高端家庭移动交互机器人的量产高地。`
