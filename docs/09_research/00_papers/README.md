## 3. 维护规则

1. 每次新增每日论文纪要时，优先使用 `YYYY-MM-DD_kinbot_arxiv_daily.md` 命名。
2. 论文摘要应采用中文转述，不直接大段复制原摘要。
3. 每篇论文至少记录：摘要要点、Kinbot 问题映射、资源消耗、优势、劣势、推荐理由和来源链接。
4. 研究结论若影响主线架构，应单独回写 `docs/00_governance/03_decision_log.md`；若只是研究输入，保留在本目录即可。
