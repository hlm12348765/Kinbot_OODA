## 1. 结论先行

如果目标是在 `3-4` 周内，把医疗事业部的“智慧医生助理”应用放到一台机器人上，做出可展示的问诊、咨询、导诊类 Demo，并用于医院沟通和国家项目申报，我的结论很明确：

- 第一优先级不应该是纯双足人形机器人。
- 最合适的形态是：`轮式类人机器人 / 轮式人形机器人 / 商用导览咨询机器人`。
- 纯双足人形可以放进方案里，但更适合作为“申报加分项”或“高举高打的形象机”，而不是本轮最稳的主演示载体。

这和你老板的直觉基本一致。原因不是“人形不高级”，而是：

- 这次核心能力是 `问诊 + 咨询 + 导览 + 展示`，不是上下楼、开门、搬运复杂物体。
- 医院和项目评审更看重“可信、稳、能讲、能演示、像个产品”，而不是单纯看双腿。
- 如果一台双足机器人最后主要站着说话，确实容易出现“形态投入远大于任务需要”的违和感。

因此，我建议把候选方案分成三层：

- `S 档`：最适合这次任务，建议立刻接触
- `A 档`：适合做项目申报加分和高端形象展示
- `B 档`：Kinbot 竞品 / 对标池，值得关注，但不建议承担本次主演示

本次最推荐的 shortlist 是：

1. `UBTECH Cruzr 1S`
2. `UBTECH Cruzr S2`
3. `KEENON XMAN-R1`
4. `Fourier GR-3`（如果你们希望更强化“医疗/陪伴/康养”叙事）
5. `UBTECH Walker C`（如果你们明确要“人形项目申报气场”）

## 2. 选型标准

本次筛选不是看“谁最火”，而是看谁更适合这次任务。我用的是下面五个标准：

1. `3-4 周落地可行性`
   - 能否快速接入语音问答、知识库、导诊脚本、多轮对话。
2. `医疗咨询场景适配度`
   - 形态、屏幕、语音、导航、停靠姿态是否自然，是否适合医院大厅、门诊区、展厅、项目路演。
3. `项目申报支撑力`
   - 厂商体量、产品成熟度、公开案例、具身智能叙事是否足够“撑场面”。
4. `形态匹配度`
   - 是否避免“太玩具”或“太工业”，同时不显得能力和形态严重错配。
5. `对 Kinbot 的参考价值`
   - 是否能作为你们未来产品路线的现实竞品或高价值对标对象。

说明：

- 下文中的评分和层级，是我基于公开资料做的工程判断，不是厂商官方评分。
- `WRC` 官网部分展商产品页会沿用同一链接、站点外壳会随年度更新；我采纳的是产品说明本身，不把站点壳上的年份当作核心事实。

## 4. S 档：最适合这次任务，建议优先接触

### 4.1 `UBTECH Cruzr 1S`

**为什么我把它放在第一梯队**

- 这是典型的 `导览 + 咨询 + 展示 + 迎宾` 机器人，不会出现“长着双腿但只负责说话”的违和感。
- 官方产品页明确强调它支持：
  - `个性化智慧迎宾`
  - `专业讲解`
  - `智能导览`
  - `多模态互动`
  - `业务咨询 / 定制问答`
  - `IoT 联动`
- 这和“智慧医生助理”在医院大厅、门诊导诊区、展会展台上的任务非常贴合。

**适合怎么演**

- 门诊预问诊：先采集主诉、生成分诊建议、推荐就诊科室。
- 智能咨询：医保、挂号、复诊、术前术后注意事项、检查流程问答。
- 科研 / 项目展示：把“智慧医生助理”包装为医院智能服务入口，而不是单点聊天机器人。

**为什么它比纯人形更适合本次任务**

- 看起来足够像“正式商用机器人”，不会像玩具。
- 又不会因为双腿过强而让人追问“那它还能做什么复杂动作”。
- 在医院这种偏保守场景里，更容易被接受。

**主要风险**

- 人形感不如全尺寸双足机器人强，申报 PPT 的“具身智能视觉冲击力”略弱。
- 如果领导非常想要“像人一样站在那儿交流”的效果，可能会觉得还差一口气。

**建议结论**

- 如果你们这次优先级是 `稳、快、像产品、像能落地的医院智能终端`，它是最优先联系对象之一。

### 4.2 `UBTECH Cruzr S2`

**为什么值得强推**

- 这是一个很有意思的中间形态：`轮式人形`。
- 官方页面给出的关键信息非常适合医院演示场景：
  - `0.8m` 通道内原地旋转 `±170°`
  - `0-0.4m` 腰部升降
  - `0-1.8m` 空间范围内搬运 `15kg`
  - 强调视觉感知、灵巧手、具身智能数据系统
- 这意味着它不是只有“说话”能力，而是已经具备一些可被展示的实体交互能力。

**它特别适合的展示方式**

- 咨询 + 导览 + 递交纸质材料 / 样盒 / 演示道具
- 陪同患者或参观者去某个功能区
- 展示“医生助理不只是会聊天，还会在真实空间里协助服务”

**为什么它比双足人形更聪明**

- 视觉上已经很“具身智能”，但结构风险比纯双足更低。
- 对医院来说，它更像下一代智慧服务机器人，而不是单纯表演型人形。
- 很适合放在“国家项目申报”的实施路径里，作为近期可落地载体。

**主要风险**

- 新一代产品属性更强，真实交付节奏、成熟度、项目配合边界需要提前问清。
- 如果你们只做纯对话，不需要任何物理操作，它的能力会有点溢出。

**建议结论**

- 如果你们想同时拿到 `医院接受度` 和 `具身智能项目感`，它可能是综合分最高的选项。

### 4.3 `KEENON XMAN-R1`

**为什么它值得进 S 档**

- `XMAN-R1` 的特殊价值，不只是它是人形，而是它来自 `KEENON` 这样的服务机器人公司。
- 擎朗不是单纯的人形创业公司，它本身长期做服务机器人，并且官网明确保留了 `医疗智慧系统` 产品线，包括：
  - `X101`
  - `M104`
  - `X202`
  - `M101`
- 这意味着它天然比很多“纯人形秀肌肉”的公司更接近真实医院场景。

**这对你们有什么价值**

- 你们卖给医院的，不只是“一个会说话的人形机器人”，而是“一个能嵌进医院服务系统的智能终端”。
- 擎朗这条线更容易讲出 `服务机器人 -> 医疗智慧系统 -> 智慧医生助理上机` 的连续故事。

**适合怎么使用**

- 如果你们希望领导、医院和项目方一眼看出“这不是传统导览机，是下一代具身服务机器人”，它很合适。
- 如果医疗事业部后续还想把导诊、陪检、送检、药品/单据递送等流程串起来，它的故事也更完整。

**主要风险**

- 双足人形仍然意味着更高的集成和演示风险。
- 对这次 `3-4` 周窗口来说，它不像成熟导览机器人那样“保守稳妥”。

**建议结论**

- 如果你们希望在“医院可接受度”和“人形项目申报叙事”之间找平衡，它是非常值得约谈的对象。

## 5. A 档：适合做项目申报加分和高端形象展示

### 5.1 `Fourier GR-3`

**为什么它很强**

- 这是我认为最值得医疗事业部认真看的 `Care-bot` 候选之一。
- WRC 展商页对它的定义非常明确：`首款主打交互陪伴的 Care-bot`。
- 官方描述里最关键的点有两个：
  - `柔肤软包覆材设计`
  - `全感交互系统`
- 这让它天然比很多硬朗的人形机更适合医院、康养、陪护、情绪安抚这类场景。

**为什么它特别契合“智慧医生助理”**

- 医疗事业部的演示如果只做“问答”，容易被看成普通大模型外壳。
- 如果上到 `GR-3` 这类 Care-bot，叙事会变成：
  - 这不是“会答题的屏幕”
  - 而是“面向医疗与康养场景的交互陪伴终端”

**适合怎么演**

- 智慧问诊助手
- 慢病随访助手
- 老年患者咨询与陪伴演示
- 康复/康养场景中的智能陪护入口

**主要风险**

- 相比成熟商用导览机器人，落地交付与快速定制能力需要尽快确认。
- 它更偏“新型交互陪伴平台”，项目合作方式可能比标准商用服务机器人更重。

**建议结论**

- 如果你们想把申报叙事往 `智慧医疗 + 康养 + 情绪交互 + 陪伴服务` 拉高，`GR-3` 是非常对路的牌。

### 5.2 `UBTECH Walker C`

**为什么它适合做形象机**

- 官方产品页对 `Walker C` 的定位非常直接：
  - `Embodied Interactive Large Model`
  - `multilingual interactions`
  - `guide services`
  - `greeting & reception`
  - `live Q&A support`
- 它已经是一个明确面向展厅、办公楼、服务中心场景的人形商用产品，不是纯科研机。

**它的优势**

- 申报 PPT、领导视察、医院路演时，视觉冲击力强。
- “中国馆导览机器人”这类公开案例，会天然抬高甲方对产品级感知。
- 163cm 全尺寸体态，更容易被理解为“未来医院服务机器人”。

**为什么我没有把它放到第一优先级**

- 你老板的顾虑是成立的：如果主要任务还是 `问诊 + 咨询 + 导览`，双足全尺寸未必是最合理的成本和风险配置。
- 对这次窗口期来说，它更像“高举高打”的展示载体，而不是“最稳的业务 Demo 载体”。

**建议结论**

- 如果你们已经决定要强化“人形具身智能”标签，`Walker C` 非常值得进入高层 shortlist。
- 但如果你们优先想把演示跑通，我仍然建议优先看 `Cruzr 1S / Cruzr S2 / XMAN-R1`。

## 6. B 档：竞品 / 对标池，值得关注，但不建议承担本次主演示

### 6.1 `Fourier GR-2`

- 官方资料强调它是 `通用人形机器人`，最高 `53` 个自由度，已在 `导览咨询、学术科研、工业制造、医疗康复` 等领域做实验性应用。
- 这说明它能力强、平台感强、技术含量高。
- 但它的问题也在于：`太通用`。
- 对你们这次“医院问诊咨询 Demo”而言，它不像 `GR-3` 那样天然贴医疗陪伴，也不像 `Cruzr` 那样天然贴导览咨询。

**判断**

- 更适合作为技术对标和竞品观察对象，而不是本次首选。

### 6.2 `Unitree G1`

- `G1` 的优势是曝光高、成本相对友好、开发者生态热，WRC 展品页也强调了它的灵活性和动态能力。
- 它很适合做“具身智能很火”的证明，也适合技术团队快速玩起来。
- 但它的主优势偏 `运动能力 / 开发平台属性`，不是医院咨询导览的产品感。

**判断**

- 如果你们预算敏感、又想先摸人形方向，可以看。
- 但如果目标是去医院做正式展示、做国家项目申报，我不建议把它放在主位。

### 6.3 `松延动力 小诺`

- WRC 产品页给出的关键词很抓人：
  - `超仿生脸部`
  - `丰富表情`
  - `商业咨询与引导`
  - `高效知识问答`
- 它确实适合做近距离交互、前台接待、品牌展示。

**为什么我没有把它往前排**

- “仿生脸”是一把双刃剑。
- 在医院里，它可能会被一部分人认为更温暖，也可能被另一部分人认为更诡异。
- 对国家项目申报来说，它的辨识度有优势，但产品稳健感未必强于前面几家大厂。

**判断**

- 可作为特色备选，但不建议做第一推荐。

## 7. 对 Kinbot 的竞品启发

如果把这次扫描反过来看，对 `Kinbot` 其实有三条很重要的启发。

### 7.1 医院场景更认可“轮式类人”，而不是执着双足

当前市场上真正贴近 `导览 / 咨询 / 讲解 / 前台服务` 的成熟产品，大多不是纯双足。

这说明：

- 机器人是否有两条腿，不是医院最关心的事。
- 医院更关心：`稳不稳、会不会说、懂不懂流程、能不能引导、像不像一个正式系统入口`。

### 7.2 “温暖感”并不等于“人形双腿”

真正决定温暖感的，是：

- 头部与屏幕设计
- 语音人格
- 回答的医疗可信度
- 交互节奏
- 陪伴与引导时的姿态设计

所以如果 Kinbot 未来要切医疗/康养展示，最该对标的不是单纯的双足能力，而是：

- `Cruzr 1S` 这类成熟咨询导览体验
- `GR-3` 这类 Care-bot 叙事
- `Walker C / XMAN-R1` 这类具身智能项目申报气质

### 7.3 市场已经出现“两条产品线”

现在市场基本在分成两条线：

- `产品化服务机器人线`
  - 强调迎宾、咨询、导览、导航、运营和场景闭环
- `具身智能形象机线`
  - 强调人形、交互、品牌高度、技术引领和项目申报势能

这次医疗事业部的需求，本质上更像第一条线，但为了项目申报，可以适度借第二条线的势能。

**首选**

1. `UBTECH Cruzr 1S`

- 希望避免“纯人形但任务不匹配”的质疑

### 方案 B：务实 + 具身智能叙事平衡

**首选**

1. `UBTECH Cruzr S2`

**适用前提**

**首选**

## 9. 我建议你们下一步怎么做

如果只给一个非常实际的行动建议，我会这样排：

1. 先联系 `UBTECH`，重点问 `Cruzr 1S / Cruzr S2 / Walker C`
2. 同时联系 `KEENON`，重点问 `XMAN-R1` 和其医疗智慧系统协同能力
3. 再联系 `Fourier`，重点问 `GR-3` 的交付节奏、软件开放度和医疗合作方式

对外沟通时，建议你们把需求明确写成：

- `3-4 周内要完成医院场景展示 Demo`
- 核心是 `问诊 / 咨询 / 导诊 / 项目展示`
- 需要 `语音多轮对话 + 知识库问答 + 路线导引 + 屏幕展示`
- 希望尽量弱化高风险动作能力，强化稳定交互与空间服务能力

这样厂商更容易给你们匹配正确产品，而不是一上来推最“炫”的那台。
