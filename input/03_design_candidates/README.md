## 目录角色

本目录用于保存外部设计候选、结构 / 交互 / 造型方案及类似 PDF 原始输入资料。

这些资料默认只是评审输入，不直接升级为产品或架构事实。只有形成经评审确认的稳定取舍时，才回写主线文档、`03_decision_log.md`、`CHANGELOG.md` 或 Linear。

## 当前资料

- `医疗交互JQR-Robot Claw方案.pdf`：医疗交互 / Robot Claw 方案候选输入，后续需按具体评审任务判断是否影响结构、交互、外观或成本主线。

## 维护规则

1. 原始资料保持原貌留存，避免在输入目录内改写为正式结论。
2. 若新增大文件，应先判断是否需要本地忽略或交付归档规则。
3. 若候选方案形成正式取舍，应在 `docs/` 下对应主线或评审文档中沉淀结论。
